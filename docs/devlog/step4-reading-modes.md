## 主要实现与决策

- `Reader.tsx`／`reading.ts` 统一三模式的页面选择、过滤、页码范围及阅读导航。整理为连续编辑；复习首次默认连续只读预览，并支持单页布局；沉浸整理隐藏目录、保留单页编辑，提供明确退出按钮。
- 模式切换不重建 DraftStore，草稿、保存队列和页面 ID 继续使用。复习直接预览本窗口当前草稿；此前编辑继续保存，但复习没有笔记编辑／问答修改、页面属性写入、目录变更、导入、清空入口。可选择目录课件与临时折叠目录、笔记区，保存失败／冲突需返回整理处理。
- 连续阅读记录首个可见原始页码及页内偏移，模式或布局切换后恢复；单页回到该页开头。页面尺寸变化时按当前锚点恢复，首次打开课件不强制跳过工具栏。单页支持上一／下一页、原始页码跳转及左右键；输入、选择框、按钮、可编辑内容和弹窗内不触发快捷翻页。目标页不符合条件时选后续首个符合页，否则末个符合页。
- 全屏与模式／布局独立，监听浏览器全屏状态；Esc 不切换阅读布局。失败或不支持时提示仍可使用窗口内布局。单页支持 75%／100%／125%／150%／200% 缩放与适应页面；PDF canvas 与文本层共用缩放比例，宽页面在局部区域滚动，窗口尺寸变化后重新计算。
- 迁移 `0006` 为页面新增 `category`、`display`、`settings_version`，旧页默认正文／正常／0，ID 和笔记内容不变。分类与显示独立；不重排或删除 PDF 原始页。
- 整理／沉浸可单页或按原始页码范围批量修改。连续模式折叠页保留页码条并可临时展开；隐藏默认跳过。单页默认跳过折叠及隐藏，提供包含折叠／显示隐藏开关；三模式均可筛选分类、显示跳过数量。空结果提供「显示全部页面」，不会自动修改持久属性。
- `PATCH /api/materials/{id}/page-settings` 校验非空不重复页面列表、所属课件、枚举和独立版本；按版本条件更新，任何一页冲突则整批回滚。前端冲突后重新读取最新属性，**只合并属性，不覆盖笔记／总结／问答及草稿**，等待用户核对后再次操作。失败保留原值，可重新选择重试。
- 阅读模式、复习布局、筛选、临时展开与缩放为当前课件会话状态；分类、显示与属性版本存储在数据库，刷新／重启保持。批量页码覆盖原始范围内的全部页，包括被筛选或隐藏的页面。

Windows 按 `npm ci` → `npm run build` → 后端启动的实际流程导入 PDF 后，页面提示 `Setting up fake worker failed`，控制台说明浏览器请求 `/assets/pdf.worker.min-CIqJB0yW.mjs` 时收到 `text/plain`，模块脚本被严格 MIME 检查拒绝。该构建产物及前端 worker 地址与 macOS 正常运行版本一致。

本机复核发现 Python 3.11 的 `mimetypes.guess_type()` 将同一个 `.mjs` 文件解析为 `text/plain`，而 `.js` 为 `application/javascript`、`.wasm` 为 `application/wasm`。原因是 Windows 与 macOS 的本机 MIME 映射不同。旧后端通过 Flask `send_from_directory` 自动推测类型，因此构建本身没有错误，平台差异发生在静态文件响应阶段。

### 主要实现与决策

- 修改 `backend/slide_notes/__init__.py` 的静态资源 `assets` 路由：扩展名不区分大小写，`.mjs` 显式使用 `text/javascript`；其他静态资源继续由 Flask 按原逻辑识别。
- 修改 `backend/tests/test_workflow.py`，新增路由级 MIME 回归测试，验证大写 `.MJS` 同样返回 `text/javascript`。
- 不修改 PDF.js 版本、worker 导入方式、Vite 构建配置或依赖锁文件；问题修复不依赖操作系统注册表设置，macOS 与 Windows 共用同一实现。
- 未修改用户已有代码注释，未操作用户数据库或当前 `5001` 后端进程。
