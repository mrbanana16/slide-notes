# v1.0.1 · Windows 维护记录

2026-11-12。本次修复按三位版本规则递增末尾版本号。

- 课件拖动使用紧凑的文件名预览。课件行用蓝线标记插入位置，课程和章节用蓝色轮廓标记归属。目录保存提示随操作结果触发。
- 清空前可在数据目录创建包含 SQLite 和原始 PDF 的备份，并从系统设置恢复。原文件无法读取时，阅读区和顶栏给出提示，可用原 PDF 恢复原课件。
- 重复导入经确认后可创建编号副本，具有独立的页面和笔记。迁移 `0008` 改用可读笔记字段，并在清空最后一项内容时移除 `page_notes` 记录。页面继续保留独立的笔记和总结版本。
- 前端测试与测试辅助文件迁至 `frontend/tests/`。页面列表批量读取笔记和问答，导入批量写入页记录，前端批量绑定草稿，连续阅读共享页面可见性观察。
- 维护提交规则增加 `docs:`，用于纯文档修订。系统设置显示完整的三位版本号。
- 选择或拖入 PDF 后，导入弹窗立即并行检查内容指纹、PDF 可读性、加密状态和页数。文件信息行显示页数，异常、加密及重复状态在确认前反馈。

## 【人工验收】

- [ ] 在 Windows 浏览器拖动课件到目录最底部的课程和章节，再拖回课程直属。检查拖动预览左侧、蓝色定位线和跨课程确认。
- [ ] 保存目录，待提示消失后切换课件或调整窗口。确认提示只出现一次，再执行一次保存，确认新操作仍会提示。
- [ ] 导入同一份 PDF 并创建两个副本。核对文件名后缀、落点和笔记隔离。
- [ ] 选择或拖入已导入过的 PDF，在确认前核对「课件已存在」、原位置和「创建副本」。换成内容不同的 PDF，核对重复提示消失。
- [ ] 在临时数据目录中保存笔记，勾选备份后清空，再从系统设置恢复。核对目录、原 PDF 和已保存笔记。另测取消及不备份清空。
- [ ] 在临时数据目录中移走原 PDF，再打开该课件。核对阅读区提示和顶栏按钮，选错文件时应报错，选择原文件后应恢复并保留笔记。
- [ ] 导入实际的 1800 页课件，检查首次打开、连续滚动、跳至末页以及笔记输入的响应。核对设置显示 `v1.0.1`。
