6. 引入项目内 `@dnd-kit/core`、`@dnd-kit/sortable`、`@dnd-kit/utilities`，参考 [Sortable 官方文档](https://dndkit.com/legacy/presets/sortable/overview/)及[键盘传感器文档](https://dndkit.com/legacy/api-documentation/sensors/keyboard/)。提供拖动预览、落点线／区域、取消拖动和中文辅助说明；自定义方向键坐标只导航到兼容类型和课程，避免键盘拖动停在不兼容的子条目。菜单提供上移、下移和章节选择，空章节展开后可接收课件。放到课件上插入对应位置，放到组区域追加末尾。
7. 导入改为原生模态弹窗：先选择课程与可选章节，再选择或拖入 PDF，明确确认后上传。没有课程可在弹窗内创建，成功后自动选中；错误时可在弹窗内重新加载目录。相同内容仍打开已有课件，保留原始归属及笔记。兼容旧上传调用未传课程时的“未分类课程”兜底。
8. 删除课件前读取页数、已保存笔记／问答计数及页面 ID，提示当前窗口未保存编辑数并确认。计数为非空个人笔记、非空总结、未删除问答分别一条；取消不改变数据。删除时暂存原文件，数据库事务失败则移回，成功级联删除并清理文件、对应页浏览器草稿与迟到保存响应，其他课件草稿继续保留。非空章节／课程拒绝删除。
9. 当前课件加载以 ID 为依赖，目录改名、排序或移动仅更新结构及面包屑，不重新加载 PDF／编辑器，继续处理草稿。同步 README 日常操作和页面／接口现状清单，保留用户代码注释。未连接浏览器、未点击 IDE 配置、未操作真实用户数据上的清空／删除接口。
