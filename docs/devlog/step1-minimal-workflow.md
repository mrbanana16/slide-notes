### 开发过程与范围

根据 `PLAN.md` 阶段一，从真实 PDF 上传、逐页显示、个人笔记保存与重启恢复建立闭环。开发前，按用户明确要求，以用户原有作者身份创建并 GPG 签名初始化提交 `0322a3068d0dd9b334887bed794c088d5df4b094`，推送到 `origin/main`；本次初始化提交不包含 Codex 协作者 trailer。签名核验通过，远程 main 与本地初始化提交一致。

界面实现使用 `frontend-design` 技能，遵循计划中的系统中文字体、灰白背景、蓝色主操作及约 60:40 的逐页课件／笔记布局。窄屏上下排列，目录可收起，输入与按钮具备键盘焦点。

### 主要实现与决策

已实现 PDF 导入、课件目录、逐页 PDF 展示和个人笔记手动保存。笔记按稳定页面 ID 存储；保存时检查版本号，防止多窗口静默覆盖。支持选择 PDF 或拖入工作区，拒绝损坏、加密、空页和超过 100 MB 的文件。

本阶段编辑纯文本及 Markdown 源码，不提供 Markdown 预览。编辑后点击每页的「保存笔记」，或在笔记输入框内按 `⌘S` / `Ctrl+S`。当前窗口内切换课件会保留未保存内容，关闭或刷新前会提示；**尚未实现自动保存及刷新后草稿恢复，关闭前请确认所有笔记已保存**。这些能力在阶段二实现。

- React + TypeScript + Vite 前端，Flask + SQLAlchemy + Alembic + SQLite 后端，Waitress 仅监听 `127.0.0.1:5001`。
- 本阶段建立 Material、Page、PageNote 数据表；每页有稳定 ID 和原始页码，个人笔记与页面一一对应。暂不提前实现课程、章节、AI 总结、问答、排序及三种模式。
- 启动时使用 Alembic 升级数据库。数据目录默认固定于 `backend/data/`，可用 `SLIDE_NOTES_DATA` 指定路径。
- PDF 经临时文件校验后使用内部课件 ID 落盘；验证页数及页面结构，拒绝非 PDF、损坏文件、空文档、加密文档及超过 100 MB 的请求。数据库写入失败会清理文件，校验失败不产生课件记录。
- PDF.js 连续逐页展示，按可视区域及邻近区域渲染，并提供文字选择层；横竖页依其尺寸显示。渲染错误有提示。worker、CMap、字体及 WASM 随构建产物提供，不依赖 CDN。
- 个人笔记本阶段采用显式保存按钮及 `⌘S` / `Ctrl+S`。显示未保存、保存中、已保存、保存失败；保存失败保留输入并允许重试。
- 保存请求附带版本号，通过数据库条件更新发现多窗口冲突，避免静默覆盖。冲突时保留输入，用户需先复制草稿，再刷新读取最新版本并手动处理。
- 保存过程中继续输入时，仅将提交的文本标记已保存；新输入仍保持未保存。切换课件时草稿保留在当前窗口，关闭或刷新前有未保存提醒。
- 自动保存、刷新后本地草稿恢复、Markdown 预览属于阶段二，尚未实现。当前必须手动保存后再关闭。
- Python 依赖安装在 `backend/.venv/`，前端依赖安装在 `frontend/node_modules/`；保留 `requirements.lock`、`package-lock.json` 及迁移脚本。

## *fix 阶段一人工反馈修复：后端日志与权限保护 PDF

日期：2026-11-03

### 人工反馈与原因

用户反馈：后端控制台没有日志和访问地址；两份可正常阅读的课件无法导入；其他事项验收通过。上文相关待办已据此勾选，历史验证记录保留；本阶段整体尚未确认通过，不提交推送，不进入阶段二。

复现两份反馈文件时，导入均返回 400“暂不支持加密 PDF”。结构检查发现它们内部带加密标记，但空密码解密成功，无需用户输入打开密码，分别为 43 页、58 页。原实现只判断 `is_encrypted` 就拒绝，误伤此类课件，与用户日常直接打开文件的体验不符。

Waitress 默认不提供访问日志，默认日志级别也不会显示普通 INFO 输出；原入口没有主动配置日志或输出地址。参见 [Waitress 日志说明](https://docs.pylonsproject.org/projects/waitress/en/latest/logging.html)。

### 修改与决策

- 后端遇到带加密标记的文件时尝试空密码读取，成功则继续页数及页面结构校验，保持原始上传字节不变；真正需要打开密码的文件仍返回 400，并明确提示“需要打开密码”。不提供密码输入或文件解密改写功能。
- `PLAN.md` 的拒绝范围同步澄清为“需要输入打开密码的 PDF”，允许无需输入密码即可读取的权限保护课件。
- `backend/run.py` 配置时间、级别及 logger 名称的 INFO 控制台输出；先创建并绑定 Waitress 服务，成功后才打印 `http://127.0.0.1:5001` 与实际数据目录。启动失败输出异常；停止时关闭服务。
- `backend/slide_notes/__init__.py` 记录请求方法、路径、状态码和耗时；不记录查询参数或笔记正文。另记录 PDF 导入 ID／页数、密码拒绝原因和解析异常栈，已有服务异常继续记录。
- 更新 README、前后端清单及范围说明；没有改动用户代码注释，也没有将用户课件加入仓库或长期测试夹具。
