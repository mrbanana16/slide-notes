# v1.1.0 · 沉浸整理合并，新增文件详情

2026-11-17

## 整理模式布局

将原沉浸整理并入整理模式。整理与复习共用「连续阅读／单页阅读」切换，工作台会话内分别记忆布局。单页整理沿用原来的编辑、导航和缩放操作，进入时默认收起目录，返回连续整理时恢复目录状态。

## 文件详情

目录课件的「⋯」菜单新增「文件详情」。标题可在详情内直接编辑，输入框失焦后保存。原始文件名显示在标题下方，与文件大小、目录路径、已保存笔记条数及导入时间同级排列。

迁移 `0009` 将旧名称保留为标题。旧库没有保存导入时的原始文件名和导入时间，详情显示「未记录」。新课件初始标题沿用上传文件名，独立副本的编号只加在标题上。

人工验收反馈已修订。菜单补上文件详情图标，弹窗标题旁沿用工作台的 PDF 图标，长标题自动换行。笔记总数下展示 AI 解释与总结、个人笔记和问答总条数。每组已保存的问答计一条，已删除的问答不计入。第二轮反馈后，笔记分项略小于父项，PDF 图标对齐标题框中线，文件大小按 B、KB 或 MB 显示，弹窗完成关闭动画后卸载。标题框隐藏滚动条，原始文件名采用与其他属性值一致的正文颜色，笔记条数及分项列在详情末尾。参照系统设置首行的间距，文件详情标题下方增加 12 px 留白。

文件详情第一项新增「原文件状态」。查找时显示黄点，文件存在显示绿点及「打开目录」，缺失时显示红点和「重新导入」。恢复沿用原文件匹配和检查流程。

### 文件详情

- [x] 在整理模式导入 PDF，核对「⋯」菜单中的文件详情图标和弹窗中的 PDF 图标。检查原始文件名、文件大小、目录路径、笔记条数和导入时间是否对齐。
- [x] 将鼠标移到标题上，核对输入框边框出现。检查单行标题框右侧无滚动条。在窄屏输入长标题，确认自动换行。点击详情内其他位置，检查自动保存、原始文件名的正文颜色，以及侧边栏、顶栏和整理界面的标题。刷新并重新打开课件，核对标题已保存。
- [x] 导入同一 PDF 并创建独立副本，核对副本标题包含编号、原始文件名保留。打开升级前导入的课件，核对标题和笔记保留。
- [x] 保存 AI 总结、个人笔记及有问题和回答的问答各一条，核对笔记统计位于详情末尾，三个分项均为一条，总数为三条。删除问答后重新打开详情，检查问答条数和总数。
- [x] 检查多行标题旁的 PDF 图标是否垂直居中，笔记分项字号是否略小于父项。用不同大小的 PDF 核对 KB、MB 显示，关闭弹窗时确认有过渡动画。
- [x] 从课件详情点击「打开目录」，检查访达或文件资源管理器是否打开并选中该课件的 `original.pdf`。用测试课件暂时移走原文件，重新打开详情，确认显示红点和「重新导入」。选择原 PDF 后核对状态恢复为正常且页、笔记保留。
