# v1.2.0 · 顶栏切换课件与课件地址恢复

2026-11-17

实现后续功能计划中的构思 2、3。悬停或点击顶栏的课程或章节名称可选择课件。课程菜单列出直属课件及按章节分组的课件，章节菜单显示该章节的课件。末级标题悬停时显示完整名称。菜单用 PDF 图标标识课件，高亮当前课件，面板内边距随窗口宽度保持在 16 至 20 px，章节分组和选项也增加了留白。课程和章节名称直接作为菜单入口。

侧栏品牌区链接到首页。首页删除导入按钮下方的两条提示，仍支持点击按钮和拖入 PDF。

整理和复习的地址分别为 `/note/{课件ID}` 和 `/review/{课件ID}`。切换模式时更新地址，刷新及前进／后退时恢复对应模式。原 `/read` 路由已移除。目录、顶栏和导入结果共用打开课件的行为。直接访问、刷新及浏览器前进／后退通过课件 ID 恢复课件。改名或移动后继续使用同一地址，保持课件、阅读位置和草稿。地址中的 ID 无法定位时提示用户并返回首页。Flask 在课件地址下提供工作台页面，目录、课件和笔记继续使用原接口。
