## 目录交互

- dnd-kit 拖动有独立把手、拖动预览与落点线；普通课程排序、同课程章节排序、课件排序及跨章节／课程移动由单次目录事务提交。可放到课程／章节标题（包括折叠状态）、课件或展开后的空组；跨课程先展示确认弹窗，确认前不提交。全部菜单操作均可用键盘完成。
- 放下后按目标立即投影显示新目录，等待响应期间禁用其他目录变更；成功采用服务器快照，失败恢复原结构。拖动浮层禁用默认回到旧位置的落下动画，原行不叠加位移。
- 系统“未分类”初始化即存在，固定在首位，不提供改名／删除／排序操作，但可接收及移出课件。清空后服务返回含此系统分类的快照，前端立即保留它。
- 课件选择按钮与「⋯」操作菜单分开；上移／下移在边界禁用，移动下拉框按课程分组列出所有课程直属与章节，跨课程选择同样先确认。目录请求进行中禁用目录操作，错误不假装已保存。
- 当前课件只在 ID 变化或显式重载时重新读取页面与 PDF；改名、排序与移动只更新目录／面包屑，编辑器及草稿继续工作。
- 目录折叠状态仅留在当前组件会话，不写入数据库；排序和归属持久化。每个课程先显示直属课件，再显示按顺序排列的章节。

## 保存与草稿行为

- 三个笔记区独立展开／折叠，默认仅展开 AI 解释与总结，个人笔记和追问解答默认折叠；折叠不会停止保存。每条问答的问题和回答组成一个保存对象，总结与个人笔记各自保存，版本互不影响。
- 停止输入约 800ms 后保存；输入框内 `⌘S`／`Ctrl+S` 或保存按钮可立即提交。每个对象串行请求，保存中继续输入时保留新内容，上一请求返回后再保存。
- `drafts.ts` 在工作台级别管理队列。切换课件后队列仍工作，草稿绑定稳定页面／问答 ID，顶部显示未保存页数；关闭或刷新时若仍未保存会提示。
- 草稿写入当前站点的 localStorage，使用 sessionStorage 中的标签页标识隔离普通独立标签页。**在同一标签页、同一访问地址刷新并重新打开对应课件**可恢复；服务器版本未变则继续自动保存，版本已变则等待选择。新标签页不会自动导入其他标签页的草稿；清理浏览器存储或改变端口／主机会影响恢复。浏览器“复制标签页”可能复制会话标识，验收多窗口冲突请从新建空白标签页访问地址。
- 存储不可用／空间不足会显示错误，内存输入仍保留，请保持页面打开并保存或复制内容。断网或后端不可用时保留草稿，不无限重试；点击“重试保存”或继续输入后可重新提交。
- 冲突不静默覆盖。显示服务器版本供比较；选择保留草稿后使用最新版本号提交，再次发生并发修改仍会再次提示。服务器已删除问答不能用旧 ID 恢复，可先复制草稿再采用服务器删除结果；孤立草稿可复制后丢弃。
- 未实际编辑的对象隐藏底部保存状态和保存按钮，即使已有服务器内容也不自动显示；开始输入后显示，保存成功后仍保留，切换课件返回不重置本次编辑标识。恢复草稿、保存中及失败／冲突不能被隐藏，保存失败文字为红色。
- Markdown 支持基础语法、表格、代码块、任务列表。代码块显示开头反引号后标注的语言，常用语言按关键字、字符串、数字、注释等分色；未知语言保留标签和原文，无语言时显示“纯文本”，行内代码不添加语言栏。预览不执行原始 HTML，图片以占位文字代替且不发出图片请求；安全链接在新标签页打开。
- AI 总结和解答由用户手动输入或粘贴，本阶段不调用 AI API。
- PDF 内容去重与阶段一一致，重复文件在弹窗直接提示原位置，可选择打开已有课件。清空成功后清理本站点全部阶段二草稿，迟到保存响应不会恢复旧数据；其他窗口需刷新。

## 界面主题

当前统一浅色：`frontend/index.html` 声明 `color-scheme: light`，`styles.css` 根元素声明 `only light`，弹窗显式设置白色表面和正文颜色，表单使用浅色控件。应用内导入／转移弹窗不随系统主题变黑。完整浅色／深色主题专项实现列入 `PLAN.md` 阶段 5，当前未实现。

## 构建与启动

PyCharm：按 README 安装更新后的依赖，停止旧 `run backend`／`backend_run` → 运行 `frontend_ci` → `frontend_build` → `backend_run` → 刷新 <http://127.0.0.1:5001/>。工作区现有 IDE 配置名为 `frontend_ci`、`frontend_build`、`backend_run`，分别执行安装、构建、服务启动，无自动串联；脚本路径、解释器要求和端口未变，后端启动自动迁移到 `0006`，旧页面新增正文／正常的属性默认值，原 ID 与笔记保持。依赖已安装则无需重新运行 `frontend_ci`；本轮须重新构建前端、停止旧后端后重启。

命令方式（项目根目录）：

```sh
npm --prefix frontend ci
npm --prefix frontend run build
backend/.venv/bin/python backend/run.py
```

接口详情见 [后端接口列表](backend-apis.md)，具体人工步骤见 [阶段四记录](devlog/step4-reading-modes.md)。

## 阅读位置与只读边界

模式、复习布局、筛选、临时展开及缩放属于当前课件阅读会话的前端状态，无独立路由或后端模式开关。切换模式保留稳定页面 ID 对应的草稿，连续布局记录可见原始页码与页内偏移；单页默认跳过折叠和隐藏，当前页不再符合条件时取后续第一符合页，否则最后符合页。首次打开课件不强制滚动到第一篇正文。

复习预览读取工作台草稿，先前编辑仍可完成自动保存；没有 textarea、添加／删除问答和页面属性写入入口。目录可选课件并临时折叠，拖动和变更菜单禁用／移除，导入与清空禁用。保存冲突需切回整理处理。全屏失败显示可继续使用窗口布局的提示；Esc 只改变浏览器全屏状态。

单页复习与沉浸整理共用四向方向键快捷键，工具栏显示说明。普通按钮聚焦（例如点击单页阅读后）仍可使用；文本框、选择框、可编辑内容、弹窗和文本输入类 ARIA 控件聚焦时保留自身键盘行为。输入法组词、修饰键组合及已被其他控件处理的事件不触发翻页。连续模式不注册此翻页处理，翻页仍使用筛选后的可见页面顺序。
