# 后续功能计划

本清单收录长期维护期间拟新增的功能。各项可按使用需求独立推进。

## 新增构思

| 编号 | 功能 | 预期行为 |
| --- | --- | --- |
| 1 | 文件详情 | 在目录课件的「⋯」菜单增加「文件详情」，显示文件名、大小、目录路径、已保存笔记条数和导入时间。 |
| 2 | 顶栏路径选择 | 鼠标移到顶栏某一级路径时展开可选列表，显示该课程及其下属章节中的课件。选择后打开对应课件，并更新顶栏路径。 |
| 3 | URL 路径与刷新恢复 | 在 URL 中显示当前课程、章节和课件路径，刷新后恢复打开的课件。用稳定的课件标识定位，处理改名、移动、已删除或无效地址。 |
| 4 | Windows 与 macOS 启动产物 | 增加自动化打包程序或脚本，生成可直接运行的 Windows `.exe` 和 macOS Shell 启动脚本，供 Release 分发。启动时先通过版本和提交标识核对发布文件是否来自同一提交，校验失败时提示并停止。然后优先检测并使用已有的可用 Python 虚拟环境。没有可用虚拟环境时检查系统中是否存在可调用且符合要求的 Python；缺失则提示并停止。找到 Python 后，在启动程序所在目录创建虚拟环境，按锁文件下载并安装后端依赖，安装成功后启动后端。 |
| 5 | GitHub Actions 自动化 | `main` 收到新推送时自动运行前后端测试和构建检查。从 GitHub 网页端手动触发发布工作流，对选定提交校验版本并打包 Windows 和 macOS 产物，再创建对应版本的 GitHub Release，上传发布文件。 |

## PLAN.md 中保留的后续功能

以下为 [PLAN.md 的后续版本规划](archive/PLAN.md#5-后续版本与技能建议)中尚未实现的功能，沿用原建议顺序。

| 阶段 | 可引入功能 | 具体内容 |
|---|---|---|
| 1. 数据管理与迁移 | 笔记搜索、Markdown 导出、完整备份恢复 | 按课程、课件搜索笔记与问答；导出时保留页码关联；统一备份数据库、课件及附件 |
| 2. 编辑体验增强 | 数学公式、图片粘贴、所见即所得编辑 | 支持 LaTeX 公式渲染、图片上传与粘贴；按需增加富文本编辑，并验证与 Markdown 的往返兼容性 |
| 3. 课件兼容与识别 | PPTX 自动转换、OCR | 保留 PPTX 原文件，转换为 PDF 后逐页整理；对扫描版课件增加文字识别，供搜索及 AI 使用 |
| 4. 复习辅助 | 复习标记、待解决问题筛选、复习进度统计 | 标记重点、待复习和已掌握页面；为问答设置解决状态；按课程或课件统计复习进度 |
| 5. AI 集成 | 一键总结、页内追问 | 支持配置 AI API，选择当前页或指定页面作为上下文；生成内容经确认后保存，可继续手动修改 |
| 6. 组织结构扩展 | 任意层级目录 | 当“课程 → 章节 → 课件”不足时，增加多层文件夹与跨目录移动，保留已有排序和笔记关联 |
| 7. 多设备访问 | 局域网访问、个人服务器部署 | 先支持电脑运行后端、平板通过局域网访问；再按需增加服务器部署、登录验证、HTTPS 和自动备份 |

**PPTX 高度还原**单独评估。复杂排版、动画、音视频内容可按需调研专用渲染方案。

多设备阶段默认由多个设备访问同一个后端。离线同步和冲突合并留待后续评估。
