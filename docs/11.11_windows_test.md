# 11.11 Windows 人工测试发现问题及各项优化

1. 侧边栏中，拖动文件时，文件对象左侧有多余的白色区块。
2. 文件块背景遮住了后面的蓝色定位线，使得线看不清楚。（可缩小拖动时的对象大小来解决）
3. 无法将文件拖动到/拖动回课程直属分类。无法将文件拖动到位于目录最底部的课程/章节。
4. 部分toast会一直无限重复弹出（如目录已保存），刷新页面才可消失。
5. 数据库字段名需要优化为易读且易理解的名称，如summary改为ai_summary、content改为personal_note等
6. 清空全部数据时询问是否要创建数据库+原始文件备份，同时提供从备份恢复功能
7. 增加课件原文件检测，若原文件无法读取则在课件显示区域显示原文件丢失提示，同时顶部提示重新导入原文件
8. 导入重复课件时不阻止，改为提示课件已存在，提示用户是否创建其副本。（若创建，则在文件名后加上一些后缀，同时做好对文件唯一性和重复文件的识别与适配，可添加必要的数据库字段解决此问题）
9. page_notes表只在笔记有内容时写入记录，没有笔记的页面不要写入
10. 前端项目文件中，test与普通代码混在一起。按照标准的TypeScript项目文件结构整理现有文件的保存位置。

【以下两点需写入AGENTS及相关文档】

1. 除现有的feat和fix提交信息开头外，增加docs: 开头，用于仅进行文件修订的commit。
2. 版本号规范修改为适应packages.json中的三位数字版本号体系：第一位数字在执行重大更新（如代码重构、大改设计）时+1（必须由用户显式说明将此数字+1）；第二位数字在推送普通feat时+1，用于小型功能更新；第三位数字在推送fix时+1，用于bug修复。

性能方面还存在问题，解决上述问题后继续尝试优化性能。测试导入一份1800页的PDF时，系统整体非常卡顿。

请注意，当前开发环境为Windows平台，与macOS可能略有差异。
