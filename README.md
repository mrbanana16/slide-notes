# slide-notes · 课件笔记整理助手

运行在本机的个人学习工作台，围绕 PDF 课件逐页整理与复习笔记。支持课程与章节管理、逐页 Markdown 笔记、多条问答、页面分类及折叠隐藏，并提供整理、复习和沉浸整理三种模式。

前端采用 React、TypeScript、Vite 与 PDF.js；后端采用 Flask、SQLAlchemy、Alembic 和 SQLite，日常运行由 Waitress 托管。首版面向本机单人使用，不包含账号、云同步或 AI API 集成。

完整范围与阶段验收标准见 [PLAN.md](PLAN.md)，开发协作规则见 [AGENTS.md](AGENTS.md)。

开发记录、自动化验证与人工验收清单按阶段维护在 [docs/devlog](docs/devlog/)，参见 [阶段一开发与验收记录](docs/devlog/step1-minimal-workflow.md)、[阶段二开发与验收记录](docs/devlog/step2-complete-notes.md)、[阶段三开发与验收记录](docs/devlog/step3-course-structure.md) 和 [阶段四开发与验收记录](docs/devlog/step4-reading-modes.md)。

阶段一至四已通过人工验收；三模式与页面取舍的开发及验证记录见阶段四记录。

## 环境与安装

使用 Python 3.11+ 和 Node.js 22.13+。在项目根目录运行：

```sh
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.lock
npm --prefix frontend ci
```

## 本地运行

### 使用 PyCharm 等 IDE 启动

先完成上方依赖安装，再用 PyCharm 打开项目根目录。项目已提供三份共享运行配置：

| 运行配置 | 配置文件 | 作用 |
|---|---|---|
| `frontend_ci` | [.run/frontend_ci.run.xml](.run/frontend_ci.run.xml) | 使用项目 Node.js 执行 `npm ci`，按锁文件安装前端依赖，不构建或启动服务 |
| `frontend_build` | [.run/frontend_build.run.xml](.run/frontend_build.run.xml) | 使用项目 Node.js 运行 `frontend/package.json` 中的 `build`，生成前端静态资源 |
| `backend_run` | [.run/backend_run.run.xml](.run/backend_run.run.xml) | 使用 `Python 3.11 (slide-notes)` 解释器运行 `backend/run.py`，启动 Waitress |

1. 确认后端配置的 Python 解释器指向本项目的 `backend/.venv/bin/python`；重建虚拟环境后，需在 IDE 中重新关联解释器。
2. 确认前端配置的 `project` Node.js 解释器已设置为 Node.js 22.13+。首次导入项目后，在 IDE 的 JavaScript Runtime 设置中确认项目默认 Node.js，不能仅依赖终端 PATH。
3. 首次安装或依赖锁文件变化后先运行 `frontend_ci`，等待安装结束；再运行 `frontend_build`，等待成功退出，再运行 `backend_run`。三份配置没有自动串联；前端代码变化后需重新构建，后端代码变化后需重启后端。
4. 打开 <http://127.0.0.1:5001>。停止服务使用 IDE 的 Stop 按钮。

后端成功绑定端口后，Run 控制台会输出访问地址和数据目录；请求日志包含方法、路径、状态码及耗时，异常另有诊断信息。后端修改后应停止旧进程并重新运行 `backend_run`。

（`frontend_build` 只构建，不会启动 Vite 开发服务器）

### 使用命令启动

先构建前端，再运行本机服务：

```sh
npm --prefix frontend run build
backend/.venv/bin/python backend/run.py
```

打开 <http://127.0.0.1:5001>。服务仅监听本机，使用 Waitress，不启用 Flask 调试模式。每次启动自动执行尚未应用的 Alembic 迁移；当前最新迁移为 `0006`：在原有课程结构上为每页新增分类、显示状态及独立属性版本；旧页默认为正文／正常，保留页面 ID、笔记、总结和问答。升级本轮代码须重新构建前端，并停止旧后端后重启，单独构建不会更新运行中的后端。按 `Ctrl+C` 停止后，用同一命令重启，课件与已保存笔记仍在。

启动后终端会显示访问地址与数据目录，操作时会输出请求日志。后端代码修改后，先停止旧进程，再执行同一启动命令。

开发时分别在两个终端运行：

```sh
backend/.venv/bin/python backend/run.py
```

```sh
npm --prefix frontend run dev
```

开发界面地址以 Vite 输出为准。

## 课程与章节

系统初始化即提供固定「未分类」，用于不需要课程归档的课件；它固定在目录首位，不可改名、删除或拖动，清空后仍保留为空分类。左侧「＋ 课程」创建其他课程；课程的「⋯」菜单可添加章节，普通课程、章节与课件均可重命名。课程内支持直属课件与可选章节。空课程／空章节可删除，非空目录需先移动或删除其内容。

拖动「⠿」可调整课程、同一课程内的章节或同一组内的课件顺序；课件可拖到其他课程／章节标题、课件行或已展开的空区域。落点线／蓝色区域提示放置位置，放到课件上时插入对应位置，放到组区域时追加到末尾。也可直接放到折叠的课程／章节标题上，移动后目标会展开。跨课程移动（包括移入／移出「未分类」）会显示源位置与目标位置，点击「确认转移」后才会更改归属；取消不改变数据。章节自身仍仅在原课程内排序。

也可使用「⋯」中的上移／下移和「移动到课程／章节」下拉框，包括移回「课程直属」。键盘聚焦「⠿」，空格或 Enter 开始，上下方向键移动，再按空格或 Enter 放下，Esc 取消；键盘拖动会跳过不兼容的条目，菜单移动也可完成相同操作。保存成功显示「目录已保存」，刷新后保持顺序；放下后先显示新位置，保存失败才恢复原位置，成功时不播放回到旧位置的动画。目录折叠仅影响本次显示。

删除课件前会显示原始页数、已保存笔记／问答条数及当前窗口未保存编辑数；确认后永久删除该课件、原始 PDF 和关联内容。已保存条数按非空个人笔记、非空总结及每条未删除问答分别计数。目录版本冲突时点「重新加载」读取当前结构，再重新操作；当前笔记草稿保留。

## PDF 导入

点击「导入 PDF」后选择课程、可选章节和文件，再点击「确认导入」。也可先将文件拖入工作区，在弹窗中确认归属；默认可选「未分类」，也可在弹窗创建普通课程。重复内容会直接提示「课件已存在」及完整课程／可选章节／课件位置；点击「打开已有课件」再进入，不自动改变当前课件或原归属。课件重命名只改变显示名称，不转换或替换原始 PDF。

支持无需输入打开密码即可阅读的 PDF，包括内部带加密标记但可用空密码读取的课件。需要打开密码的文件须先解除密码保护再导入。系统保留上传文件的原始内容。重复导入按文件内容识别，提示已有课件位置并保留笔记；即使改名也不会重复创建。同名但内容不同的文件仍可独立导入。

现阶段页面及应用内弹窗、表单统一使用浅色设计，不随系统深色模式变化；完整主题适配安排在开发计划阶段 5。

## 逐页笔记

每页提供「AI 解释与总结」「个人笔记」「追问与 AI 解答」三个独立折叠区，默认仅展开 AI 解释区。总结和回答由你手动输入或粘贴，不调用 AI 服务。问答可添加多条，删除前需确认。

输入框支持 Markdown 源码，点「预览」查看基础排版、表格和代码块；代码块在开头的三个反引号后注明 `python`、`js`、`java` 等语言，即可显示语言标签和语法高亮，未注明或未支持的语言保留原文。预览不执行 HTML、不加载图片。停止输入约 800ms 自动保存，也可使用保存按钮或输入框内的 `⌘S`／`Ctrl+S`。每个笔记对象在本次打开后首次实际编辑前隐藏底部保存提示和按钮，编辑后显示；保存失败以红色提示，恢复草稿与异常状态也会显示。

保存中可继续输入、折叠区域或切换课件；顶部显示未保存页数。网络或服务恢复后点击「重试保存」。未保存草稿留在浏览器本地，在同一标签页、同一地址刷新后重新打开课件可恢复；请保留该标签页，勿清理站点存储。存储失败时会提示，请先保存或复制内容。

多窗口修改同一对象时显示版本冲突和服务器内容，保留你的输入，等待你确认使用服务器版本或用草稿重新保存。已在另一窗口删除的问答不能覆盖恢复，可复制草稿后新建问答。

## 阅读模式与页面取舍

顶部可切换「整理」「复习」「沉浸整理」。整理模式连续展示左侧课件与右侧编辑区；复习首次默认连续阅读，所有笔记以 Markdown 预览，目录只能选择课件和折叠，不能修改结构、导入、删除、清空或修改页面属性。复习可独立选择连续／单页阅读，以及进入／退出全屏。此前编辑的草稿继续自动保存，复习预览包含当前窗口草稿；保存失败或冲突时切回整理处理。

沉浸整理隐藏目录，单页并排编辑，窄屏上下排列；「退出沉浸」回到整理。单页阅读支持上一页／下一页、原始页码跳转、方向键（←／↑ 上一页，→／↓ 下一页）、缩放及「适应页面」。输入框、选择框、可编辑内容或弹窗获得焦点时不触发方向键翻页，输入法组词及带修饰键的方向键也不触发；普通按钮聚焦后仍可翻页。切换模式与阅读布局保留当前页和草稿；连续布局按当前页及页内位置恢复，单页布局回到该页开头。切换后若当前页不符合筛选条件，定位下一符合页，无后续页时定位最后一页。

「全屏」与阅读布局独立；按 Esc 或「退出全屏」退出，不改变模式或连续／单页布局。浏览器拒绝或不支持全屏时会提示，仍可在当前窗口阅读或沉浸整理。

整理和沉浸模式中，每页可独立选择分类（正文、封面、目录、未讲内容、拓展知识、其他）和显示状态（正常、折叠、隐藏）；更改分类不会改变显示状态。折叠页在连续列表保留页码条，可「临时展开」；隐藏页默认跳过。单页模式默认同时跳过折叠与隐藏页，工具栏显示跳过数量，可勾选「包含折叠页」「显示隐藏页」。筛选和临时展开仅影响当前阅读会话，不保存为页面属性。

「批量页码」使用原始页码，例如 `1-3,5`，可同时设置分类及显示状态；「保持」表示该属性不变。批量操作覆盖范围内的页面，包括当前筛选或隐藏的页面。属性保存失败时原状态保留，可重新选择重试；多窗口冲突整批回滚并刷新最新属性，核对后再次操作，不自动覆盖，也不改变笔记草稿。没有可见页面时点「显示全部页面」恢复浏览，再将需要的页面状态改为正常。刷新／重启后分类及显示状态保持，原始页码与笔记绑定不变。

## 数据位置

默认数据目录固定为 `backend/data/`，不随启动工作目录改变：

```text
backend/data/
├── app.sqlite3
├── materials/<内部课件ID>/original.pdf
└── tmp/
```

可以通过 `SLIDE_NOTES_DATA` 环境变量指定其他绝对路径。升级前已经存在的重复课件会保留，避免丢失各自笔记；升级后继续导入相同内容时会提示其中一份已有课件的位置。文件、数据库和环境文件均在 Git 忽略范围内；请勿将个人课件放入源码目录。

PDF.js worker、中文字体映射、标准字体和 WASM 资源随构建产物本地提供，安装依赖后，日常运行不需要联网。


## 清空全部数据

为方便测试，目录底部提供「清空全部数据」。点击后需再次确认，才会删除所有普通课程、章节、课件、原始 PDF、已保存笔记和当前窗口草稿，重建空数据库并清理上传临时文件，返回仅含固定「未分类」的初始页面。该操作无法撤销；取消确认不会删除数据。下载目录中的源文件不受影响。

清空期间暂停当前窗口导入，完成后可以重新导入课件。其他已打开的标签页请刷新，旧页面保存会因记录已删除而失败。清空只处理系统管理的数据库及 `materials/`、`tmp/`，不会删除数据目录中的无关文件。
