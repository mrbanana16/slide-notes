# slide-notes · 课件笔记整理助手

本项目是运行在本地的个人学习工作台。导入 PDF 后，可以按课程和章节整理课件，在阅读时逐页记录 Markdown 笔记、总结和问答，是基于课件的笔记整理和复习工具。

## 安装与启动

需要 Python 3.11+ 和 Node.js 22.13+。在项目根目录创建虚拟环境并安装后端依赖。

```sh
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.lock
```

### 使用 PyCharm

1. 打开项目根目录，将共享 `run` 配置的 Python 解释器关联到 `backend/.venv/bin/python`，将项目的 JavaScript Runtime 设置为 Node.js 22.13+。
2. 选择 `run` 并启动。配置会依次安装前端依赖、构建页面并启动本机服务。
3. 服务启动后会打开系统默认浏览器。也可以手动访问 <http://127.0.0.1:5001/>。使用 IDE 的 Stop 按钮停止服务。

### 使用终端

从项目根目录依次执行以下命令。

```sh
npm --prefix frontend ci
npm --prefix frontend run build
backend/.venv/bin/python backend/run.py
```

前两条命令负责安装和构建，最后一条负责启动服务。平时使用同一版本时可直接运行最后一条命令。更新项目后，先停止旧服务，再重新安装前端依赖、构建并启动。终端中按 `Ctrl+C` 可以停止服务。

服务只监听本机，依赖安装并构建后可离线使用。课件和已保存笔记会在重启后保留。

## 导入和组织课件

1. 点击「导入 PDF」或把文件拖进工作区。
2. 选择课程、可选章节及文件，再点「确认导入」。也可从下拉菜单末尾创建课程或章节。
3. 无需归档时选择固定的「未分类」。课程直属的课件选择「课程直属（无章节）」。

上传上限为 100 MB，支持能直接打开或可用空密码读取的 PDF。需要打开密码的文件须先解除保护。系统保留原始文件，按内容识别重复课件。出现「课件已存在」时，可以核对其位置并选择「打开已有课件」。同名但内容不同的文件可以独立导入。

目录「＋」用于创建课程。课程的「⋯」菜单可以添加章节，课程、章节和课件都可以从各自的菜单重命名。目录标题最多两行，把鼠标移到目录或顶栏的课件名上即可查看完整文件名。

- **排序与移动**。拖动标题可以排序，把课件拖到课程或章节标题上可以移入。也可以使用「⋯」菜单的上移、下移和「移动到…」。跨课程移动需要确认，取消后保留原归属。
- **键盘操作**。目录可用方向键浏览和展开。排序和移动可通过操作菜单完成。
- **删除**。普通课程和章节为空时可删除。删除课件前会显示页数、已保存内容和未保存编辑数。确认后会永久删除应用内的课件及相关内容，磁盘上的导入来源文件仍保留。

## 阅读与整理

| 模式 | 适用场景与操作 |
| --- | --- |
| 整理 | 连续显示课件与笔记，适合逐页阅读和编辑。 |
| 复习 | 以 Markdown 预览浏览笔记，可切换连续或单页阅读。目录可浏览，笔记和目录内容只读。 |
| 沉浸整理 | 默认收起目录，集中编辑单页。用顶栏菜单展开目录，点击「退出沉浸」返回整理。 |

- **跳页**。在顶栏输入原始页码并回车。单页模式还可用上一页、下一页或方向键翻页。编辑文本时，方向键按输入框原有方式工作。
- **缩放与分栏**。单页模式可调整缩放或选择「适应页面」。宽屏可拖动目录和 PDF 旁的分隔线，或聚焦分隔线后按左右键调整。窄屏通过顶栏菜单打开目录抽屉，课件与笔记上下排列。
- **折叠页面**。用页码左侧的图标折叠或展开。宽屏悬停或聚焦时显示图标，窄窗口及触屏常显。折叠后保留页码，三种模式都可保存折叠状态。
- **全屏**。点击顶栏全屏图标进入，按 Esc 或点「退出全屏」返回。模式和当前页保持。

## 逐页笔记

每页有「AI 解释与总结」「个人笔记」「追问与 AI 解答」三个笔记整理板块，各个板块采取可折叠设计。

编辑区支持 Markdown，点「预览」可查看排版、表格和代码块。在代码围栏后注明 `python`、`js` 等语言可显示语法高亮。预览不会执行 HTML 或加载图片。

- **保存**。停止输入约 800 ms 后自动保存，也可在输入框中按 `⌘S` 或 `Ctrl+S`。板块标题旁的黄点表示未保存，红点表示保存失败。该板块保存完毕后圆点消失。
- **保存记录**。点击顶栏的保存状态可查看最近五条记录，手动操作带「（手动）」标记。
- **重试**。在失败通知或保存日志中点击「重试」。连接中断时，系统显示倒计时，连接检查成功后自动尝试保存本地草稿。
- **恢复草稿**。在同一标签页、同一访问地址刷新后，重新打开对应课件即可恢复未保存草稿。保留该标签页及其站点存储。遇到存储失败提示时，及时保存或复制内容。
- **处理冲突**。多标签页修改同一条内容时，从顶栏点击「查看冲突」，比较双方内容，再选择使用服务器版本或用当前草稿重新保存。问答已在另一窗口删除时，可以复制草稿后新建问答。

## 系统设置与数据

从目录底部打开「系统设置」。可选浅色、深色或跟随系统，PDF 保持原色。面板可以检测后端运行状态，并在底部显示构建时间、启动时间和版本号。

默认数据位于 `backend/data/`，包含数据库 `app.sqlite3`、课件目录 `materials/` 和临时目录 `tmp/`。可设置环境变量 `SLIDE_NOTES_DATA` 指定其他绝对路径。备份时先停止服务，再复制整个数据目录。浏览器里尚未保存的草稿不在该备份内。

如需清空，在整理模式打开「系统设置 → 清空全部数据」，核对提示后确认。该操作会永久删除应用内的课程、章节、课件及笔记，并清理浏览器中的应用草稿，保留空的「未分类」。完成后请刷新其他已打开的标签页。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 浏览器没有自动打开 | 在终端或 PyCharm 控制台确认服务已启动，再手动访问 <http://127.0.0.1:5001/>。 |
| 服务提示端口占用 | 先停止上次运行的服务，再重新启动。 |
| 更新后仍看到旧界面 | 停止旧服务、重新构建并启动，再刷新浏览器。可在系统设置核对版本和构建时间。 |
| 目录操作提示版本冲突 | 点击「重新加载」获取最新目录，再重做操作。笔记草稿会保留。 |
